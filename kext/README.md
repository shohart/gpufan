# SMCSuperIO с управлением вентиляторами Nuvoton NCT679x

Системный компонент. Кекст — плагин VirtualSMC (замена штатного `SMCSuperIO.kext`, тот же bundle id `ru.joedm.SMCSuperIO`).
Он публикует вентиляторы материнской платы как обычные SMC-вентиляторы Apple, поэтому их видят и могут
ими управлять любые программы: `gpufan`, iStat Menus, Macs Fan Control, smcFanControl.
База — VirtualSMC 1.3.8, изменения только в `NuvotonDevice.{hpp,cpp}` (`nuvoton-fan-control.patch`).
Управление включается только на NCT6779D / NCT679xD, остальные чипы работают как в апстриме.

## SMC-ключи (n = 0…FNum-1)

| Ключ | Тип | Доступ | Смысл |
|---|---|---|---|
| `F<n>Ac` | fpe2 | R | текущие обороты, RPM |
| `F<n>ID` | {fds | R | описание вентилятора, имя (SYSFAN, CPUFAN, AUXFAN0… или `fan<n>-name`) |
| `F<n>Md` | ui8 | RW | 0 — BIOS SmartFan; 1 — ручной по оборотам (как у Apple); 2 — ручной по скважности |
| `F<n>Mn` | fpe2 | RW | минимальные обороты (нижняя граница цели в режиме 1) |
| `F<n>Mx` | fpe2 | RW | максимальные обороты (по умолчанию растут до максимума, который удалось наблюдать) |
| `F<n>Pw` | ui8 | R | фактический PWM на выходе чипа, 0…255 (в любом режиме) |
| `F<n>Tg` | fpe2 | RW | цель: RPM в режиме 1, проценты 0…100 в режиме 2 |
| `FNum` | ui8 | R | число вентиляторов |
| `FS! ` | ui16 | RW | битовая маска ручных вентиляторов, как на старых Mac (бит n → режим 1) |

Режим 1 (RPM): замкнутый контур, раз в секунду, по тахометру. Прямая связь `PWM ≈ 255·Tg/Mx` плюс ПИ-регулятор,
шаг не больше 24/255 за такт, антивиндап. Кекст сам находит порог остановки вентилятора: если тот стоит при ненулевом PWM,
поднимается нижняя граница. `Tg = 0` означает «цель ещё не задана» — удерживается текущий PWM. Ноль здесь намеренно не
останавливает вентилятор: сторонние утилиты выставляют режим раньше цели, и остановка в этом
промежутке оставила бы процессор без обдува. Чтобы задать обороты явно, используйте режим 2. Если тахометра нет, регулятор уходит в 255 (безопасная сторона).

Режим 2 (duty): `PWM = Tg·255/100`, без обратной связи. Точный режим для демона и GUI.

Гарантии:
- к портам SuperIO обращается только таймер кекста, записи ключей лишь ставят запрос (нет гонки bank-select);
- ручной режим заново выставляется каждый тик (после сна BIOS возвращает SmartFan);
- при `Md = 0` восстанавливается исходное значение регистра режима BIOS;
- опционально watchdog: boot-arg `ssiofanwd=<сек>`. Если в течение этого времени нет записей `Md/Tg`, все вентиляторы возвращаются BIOS.
  По умолчанию выключен, иначе сломались бы сторонние утилиты, которые пишут один раз.

Регистры (как в Linux `nct6775`): FAN_MODE `0x102 0x202 0x302 0x802 0x902 0xA02 0xB02` (верхний ниббл 0 = manual),
PWM `0x109 … 0xB09`, текущий PWM `0x01 0x03 0x11 0x13 0x15 0xA09 0xB09`.

## Настройка через config.plist (необязательно)

`DeviceProperties → Add → <путь LPC, например PciRoot(0x0)/Pci(0x1F,0x0)>`:

| Свойство | Тип | Пример |
|---|---|---|
| `fan2-min` | Data, 2 байта LE | `2C01` = 300 RPM |
| `fan2-max` | Data, 2 байта LE | `DC05` = 1500 RPM |
| `fan2-name` | Data/String, ≤12 символов | `GPU front` |

Значения для вставки печатает `sudo ./tools/gpufan calibrate <n>`.

## Сборка

- `build.sh` — нативная сборка на маке (Command Line Tools); сама клонирует VirtualSMC 1.3.8,
  Lilu и MacKernelSDK в `kext/build/deps`. Результат — `kext/build/SMCSuperIO.kext`;
- `build-linux.sh` — кросс-сборка (clang + ld64 из cctools-port, MacKernelSDK, VirtualSMC 1.3.8).

Флаги как у Xcode kernel-extension: `-mkernel -fapple-kext -DKERNEL -DKERNEL_PRIVATE -DDRIVER_PRIVATE`, заголовки MacKernelSDK.
Для clang ≥ 15 нужен `-mllvm -disable-atexit-based-global-dtor-lowering`, иначе появляется импорт `___cxa_atexit`, которого нет в ядре.
Проверка после сборки: импорты = импорты официального 1.3.7 + `_mach_absolute_time`, `_absolutetime_to_nanoseconds`, `_strncmp`.

## Установка

`zsh kext/install.sh` → перезагрузка → `./tools/gpufan doctor`.

Скрипт собирает кекст, если он ещё не собран, кладёт его в `EFI/OC/Kexts`, сохраняя прежний
рядом как `SMCSuperIO.kext.bak-<дата>`, и проверяет, что в `config.plist` он включён и стоит
после Lilu и VirtualSMC.
